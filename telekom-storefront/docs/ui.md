# UI and content guidelines

- Use sentence case and concise, task-specific labels. Use informal address in German and plain language in English.
- Keep both languages in sync. German text lives in the page markup and English text is keyed in `dist/assets/language.mjs`. Keep link targets and section IDs identical across languages.
- Keep the visual hierarchy in the existing stylesheet. Reuse the accent, surface and border tokens. Check contrast and preserve visible focus rings.
- Check the home page around 390 px and 1280 px wide. Cards and form controls must wrap without horizontal scrolling.
- Use labels for inputs and let validation work with the keyboard. Announce postcode results in the existing live status region.
- Keep the training footer and title. Use original imagery and sample content suitable for staging. Confirm any real products or claims before adding them.
